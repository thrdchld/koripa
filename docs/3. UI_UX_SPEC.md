# UI_UX_SPEC.md

# KORIPA

## Komitan Riset Produk Affiliate

Version: 1.0

---

# TUJUAN DOKUMEN

Dokumen ini mendefinisikan standar UI dan UX KORIPA.

Tujuan utama:

* Menghilangkan kebingungan pengguna
* Mengurangi revisi UI
* Menjamin konsistensi
* Menjamin responsivitas
* Menjamin aksesibilitas
* Menjamin pengalaman yang baik di mobile dan desktop

Dokumen ini memiliki prioritas lebih tinggi daripada preferensi visual developer.

Jika terjadi konflik antara desain dan usability:

Pilih usability.

---

# FILOSOFI DESAIN

KORIPA bukan aplikasi untuk developer.

KORIPA adalah aplikasi untuk affiliate marketer dan content creator.

Sebagian besar pengguna:

* Tidak teknis
* Menggunakan HP
* Ingin cepat menemukan produk
* Tidak ingin belajar sistem yang rumit

Karena itu:

Kesederhanaan lebih penting daripada keunikan.
