# KORIPA

## Komitan Riset Produk Affiliate

Version: 1.0

---

# TUJUAN DATABASE

Database harus dirancang untuk:

* Menampung ribuan hingga puluhan ribu produk
* Mendukung multi marketplace
* Mendukung AI metadata
* Mendukung SEO
* Mendukung collections
* Mendukung insight articles
* Mendukung audit log
* Mendukung import queue
* Mendukung soft delete
* Mendukung versioning
* Mudah dikembangkan di masa depan tanpa migrasi besar

Database menggunakan PostgreSQL di Supabase.

---

# DESIGN PRINCIPLES

1. Tidak ada hard delete.

2. Semua entitas utama memiliki:

   * created_at
   * updated_at

3. Semua produk menggunakan UUID.

4. Semua relasi menggunakan foreign key.

5. Semua URL menggunakan slug.

6. Marketplace harus fleksibel.

7. Metadata AI dipisahkan dari data produk inti.

8. Semua status menggunakan enum.

# TABLE: admins

Menyimpan daftar admin yang diperbolehkan login.

Fields:

id UUID PRIMARY KEY

email TEXT UNIQUE NOT NULL

name TEXT

is_active BOOLEAN DEFAULT TRUE

created_at TIMESTAMP

updated_at TIMESTAMP

# TABLE: products

Data inti produk.

Fields:

id UUID PRIMARY KEY

name TEXT NOT NULL

slug TEXT UNIQUE NOT NULL

long_description TEXT

subcategory_id UUID REFERENCES subcategories(id)
