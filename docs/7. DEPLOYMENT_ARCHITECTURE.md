# TUJUAN DOKUMEN

Dokumen ini mendefinisikan arsitektur deployment KORIPA.

Tujuan utama:

* Gratis semaksimal mungkin
* Mudah dipelihara
* Mudah dipindahkan ke platform lain
* Aman
* Stabil
* Tidak bergantung pada satu vendor

Arsitektur harus mendukung ribuan produk tanpa perlu perubahan besar.

# PRODUCTION PRINCIPLE

Aplikasi harus tetap berjalan meskipun:

Marketplace berubah

Import gagal

Provider down

Karena sistem harus selalu memiliki fallback.

---

# FINAL PRINCIPLE

KORIPA harus menjadi aplikasi yang dapat berjalan selama bertahun-tahun dengan biaya serendah mungkin, mudah dipelihara oleh satu orang, dan mudah dikembangkan tanpa membongkar fondasi yang sudah ada.
